# hyperframes-skill

Les 21 skills [HyperFrames](https://github.com/heygen-com/hyperframes) (HeyGen, Apache-2.0) utilisés pour tous les visuels, vidéos et animations Panier Sympa.

Installés avec : `npx skills add heygen-com/hyperframes --all`

Point d'entrée : le skill `hyperframes` (`.claude/skills/hyperframes`).
Mise à jour : `npx hyperframes skills update`.
